# Changelog

All notable changes to Concept Loom are documented here.

## Unreleased

### Added

- One-command DeepSeek Harness setup for the Desktop GUI: the installer writes `.dsh/mcp.json` for the `dsh-workspace-mcp` plugin, so each learning folder gets its own MCP process and local state.
- `concept-loom-setup` executable, a `dsh` host alias, and a DeepSeek Harness default when the host is omitted.
- Safe `.dsh/mcp.json` merge that preserves unrelated servers and refuses to replace a conflicting `concept-loom` entry.

### Changed

- `--patch` is now an explicit CLI mode for setups without `dsh-workspace-mcp`; it is no longer generated by default.
- The installer warns when the learning folder sits inside a Git repository, where DSH will not discover its project skill.

### Fixed

- Generated `.dsh/mcp.json` now uses `cwd: ".."`. `dsh-workspace-mcp` resolves `cwd` relative to the config file, so `"."` pointed the bridge at the hidden `.dsh` folder; `".."` restores the learning workspace root for notebooks and session state.
- Due-review discovery now falls back to `lastSuccessfulRetrieval`, `lastAttemptAt`, or the session's `updatedAt` for legacy evidence without `reviewAfter`, and marks those entries with `inferred: true`.

## 1.1.0 — 2026-10-06

### Added

- DeepSeek Harness adapter with native `.dsh/skills` discovery.
- Generated Harness MCP patch for Web and headless profiles.
- Installer coverage for normal and `--skip-mcp` DeepSeek Harness setup.
- Open-response checkpoints for free recall, prediction, debugging, and transfer.
- Confidence calibration and per-concept evidence for recognition, recall, application, and transfer.
- Guided, practice, review, and challenge session modes.
- Delayed review scheduling and due-review discovery across sessions.
- Explicit route extensions for prerequisites discovered during Build.

## 1.0.0 — 2026-10-01

First public release.

### Included

- Portable Concept Coach skill for Codex, Claude Code, and OpenCode.
- Locate → Weave → Build learning workflow.
- Concealed-answer checkpoints with explicit knowledge-gap handling.
- Persistent Markdown notebooks and resumable learning state.
- Save-before-continue behavior after learner responses.
- Terminal-readable text and Mermaid diagrams without image renderers.
- Learning workflows for both supplied source materials and foundational topics.
- Safe workspace installer and bilingual English/Russian documentation.
